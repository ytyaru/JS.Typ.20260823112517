# Validation

```javascript
Vdp.some(...values)
Vdp.within(v, min, max);
Vdp.po2(v, e); // Power of 2. 検査対象:v, 2の指数:e
Vdp.i8(v); // [iu](8|16|32|64|128|256|512|1024|...)
Vdo.some(...values)
Vdo.has(...keys); // Object(Function), Class, Instanceは指定のプロパティを持っているか（getter/setterも含む）
Vdo.has[GSAPM](...keys); // getter/setter/accessor/property/method 指定したkeyのそれを持っているか
Vdd.some(...values)
```

```javascript
Vd.rng(min,max).within(v)
Vd.rng(min,max).without(v)
Vd.itm(...items).some(v)
Vd.itm(...items).has(v)
Vd.itm(...items).has[GSAPM](v)
```
