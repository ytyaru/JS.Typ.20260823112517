## パス文字列から判定APIを呼び出す

現状のtis/towルートAPIは以下のようになっている。

```
tis(v); 
tow(v);
```

これを任意で第二引数まで受け付けるようにする。

```
tis(v, path); 
tow(v, path);
```

第二引数pathの内容はAPIのパス文字列（完全名／短縮名）である。
パス文字列からtis/towの対象子関数オブジェクトを取得し実行する。

通常は素直に`tis.num.inf(v)`のように呼び出す。
しかしこのpathを使えばオブジェクト参照ではなく文字列で呼び出せる。
`tis(v, 'num.inf')`のように。

使用する場面としてはtowで例外発生した時に表示されるパス文字列を引数に渡すことで判定APIを呼び出すなど。尤も、例外発生メッセージの中には短縮名もあるため、オブジェクト参照すれば済む話なのだが。

他にはJSONなど関数オブジェクトを保持できない場面でも文字列ならば保持できる。この時、パス文字列で型指定できると助かる。むしろ文字列で指定できなければ型指定できないため、パス文字列による型指定という方法は保証すべきだ。

```javascript
{
  name: 'str',
  age: 'int',
  items: 'ary<cls<Item>>',
  say: 'fn.s',
}
```




もし存在しないパスであれば例外発生する。

```
ReferenceError: 指定されたパスは存在しません。: ${path}
```
